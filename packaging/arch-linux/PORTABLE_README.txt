PIKMIN NATIVE - PAQUETE PARA ARCH LINUX

Mantén los archivos "pikmin" y "pikmin-launcher" en esta misma carpeta.
Ejecuta "pikmin-launcher" y selecciona una imagen ISO/GCM legal y sin
comprimir de Pikmin USA Rev. 1 (GPIE01, revision 1).

El launcher extrae los datos necesarios en la carpeta de instalación elegida.
La ROM no se copia ni se modifica. Para los selectores gráficos se necesita
zenity o kdialog.

Dependencias de ejecución en Arch:
  sudo pacman -S --needed sdl2 mesa libglvnd zenity

Este paquete no contiene datos de Nintendo.
